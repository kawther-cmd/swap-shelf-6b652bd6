# Swap Shelf

Build a modern, responsive React website called Swap Shelf, a university book exchange platform where students can swap, buy, and borrow books.

1. Design System
- Main colors: soft lavender, purple, white, and warm cream.
- Use a clean, modern, friendly university-community aesthetic.
- Rounded cards, subtle shadows, smooth hover effects, and readable typography.
- Keep the interface elegant, simple, and easy to navigate.
- Make the website fully responsive on desktop, tablet, and mobile.

2. Navbar
Create a shared navigation bar containing:
- Swap Shelf logo with a book icon.
- Home
- About
- Login
- Register
- Search field
- User profile icon

3. Home Page
Create a beautiful landing page:
- Hero title: "Give Books a Second Life."
- Subtitle: "Swap, buy, and borrow books easily with your university community."
- Two buttons: "Explore Books" and "Learn More".
- A large illustration/graphic of stacked books on the right.
- Book category buttons: All Books, Textbooks, Novels, Self-Help, Science, Others.
- A Featured Books section.
- Book cards with book cover, title, category, availability type (Swap, Buy, Borrow), and a favorite icon.
- A community section titled "A Smarter Way to Share Books".
Use sample book data for now. Keep book-related components modular so another developer can extend them later.

4. Required Pages
Create these separate pages:
- Home
- Login
- Register
- About
Login and Register should contain frontend forms only. Do not implement real authentication.

5. About Page
Explain the purpose of Swap Shelf: helping university students share educational resources through exchanging, buying, and borrowing books.

6. Technical Requirements
- Use React with Vite.
- Use reusable functional components.
- Use React Router for navigation.
- Keep components and pages organized in separate folders.
- Use clean, readable code with meaningful filenames.
- Do not use a backend, database, or real authentication.
- Do not add unnecessary features outside this project scope.

7. Team Collaboration
This is a university team project with three developers.
Structure the code so each developer can continue working on separate components without rewriting the entire application.
Keep the Navbar, routing, Login, Register, and About components independent.
Keep the Home page and book components modular.
Leave search, filtering, sorting, and other interactive features easy to extend.

Important: Build a working React application, not just a static screenshot. All navigation links and buttons should work where applicable.
